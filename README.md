# Gravitas

A 2D space-themed platformer made for my Grade 12 capstone project. The goal: learn Unity, C#, and 2D physics.

## About

Jump, dodge, and navigate through space and underground caves in this gravity-based platformer. Play as an astronaut in space, then as Golden Knight (Clash Royale) exploring Earth's depths.

## Features

- **2 complete levels** - Space station and underground cave
- **UFO powerup** - Ignore gravity and fly in all directions
- **Checkpoints** - Because dying to spikes repeatedly is not fun
- **Enemy UFOs** - They exist and they're mildly threatening
- **Synthwave aesthetic** - Dark blues, purples, neon lights
- **Lava, spikes, and all the classics** - Standard platformer hazards

## Controls

- **WASD** - Move
- **Space** - Jump
- **While in UFO mode** - Free 8-directional flight

## Development Highlights

- 76 hours of work over ~2 months
- First time using Unity
- One particularly bad debugging session resulted in crying for 15 minutes (almost broke laptop)

## Levels

1. **Space Level** - Astronaut navigating a space station with obstacles and UFO enemies
2. **Earth Level** - Golden knight from Clash Royale descending into caves with water, buttons, and doors
